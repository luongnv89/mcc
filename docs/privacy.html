Privacy policy

mcc runs on your computer. It has no accounts, no telemetry and no analytics, and the project receives no data from you.

Summary #

No telemetry

mcc does not report usage, crashes or any other data to the project or anyone else.

Local files only

Everything mcc stores stays in your home directory, mostly under ~/.mcc.

One network call, optional

mcc list and mcc usage ask Anthropic for each account's usage. You can turn this off.

No cookies on this site

This website sets no cookies and loads no analytics, fonts or scripts from other hosts.

What mcc reads #

To do its job, mcc reads these files and settings on your computer. None of it leaves your machine except as described under Network requests.

  • Your Claude Code setup: ~/.claude, ~/.claude.json and each profile directory, to copy, sync and count settings, skills, agents, plugins, MCP servers and hooks.
  • Your shell environment: your OS, terminal, shell, $PATH, and your shell rc files (.zshrc, .bashrc, fish config and similar), to check that a new alias doesn't clash with an existing command and to manage its own alias block.
  • Claude Code logins, only for the usage feature: each profile's .credentials.json, or on macOS the Keychain item Claude Code created for that profile. The access token is held in memory for the request and then discarded.
  • Account status: mcc runs claude auth status to show which account each profile is signed in to.

What mcc stores #

mcc writes only to your home directory (or to MCC_HOME if you set it):

LocationContents
~/.mcc/config.tomlDetected environment (OS, shell, rc file, claude path) and the list of profiles
~/.mcc/profiles/<alias>/Each profile's Claude Code configuration. Claude Code itself stores that profile's login and history here
~/.mcc/shared/projects/Session transcripts of the profiles you opted in with mcc share. It exists only once sharing is turned on
~/.mcc/logs/mcc.logA log of each command's steps and results, which can include file paths and a profile's account email. It never contains access tokens
~/.mcc/backups/, <profile>/.mcc-backup/Copies of your rc file and of the profile files a sync overwrites or removes, taken before mcc changes them, and session files that mcc share could not merge
~/.local/bin/<alias> and your rc fileThe launcher for each profile and a marked alias block

Usage results are shown and discarded; mcc does not save them.

Network requests #

Usage lookups

mcc list and mcc usage send one HTTPS request per signed-in profile to Anthropic's usage endpoint, https://api.anthropic.com/api/oauth/usage. Each request carries:

  • that profile's own access token, in the Authorization header
  • a User-Agent of mcc/<version>

Anthropic returns the percent of the 5-hour and weekly limits used and when they reset. A token is never sent to any other host, never sent for another profile, and never sent once it has expired. mcc never refreshes tokens.

The only exception is the MCC_USAGE_URL override, intended for testing. It accepts only https:// URLs or http:// on your own machine (loopback); any other value is refused and nothing is sent.

Claude Code sign-in and sign-out

mcc add runs claude auth login, and mcc delete runs claude auth logout. Those are Claude Code's own commands. They talk to Anthropic under Anthropic's terms, and mcc does not see your password or the sign-in exchange.

Installing mcc

The install script, cargo install and brew install download mcc's source from GitHub and its dependencies from crates.io. Homebrew also downloads its own Rust to build mcc. Those services see the request like any other download.

mcc makes no other network requests.

Third parties #

  • Anthropic receives the usage requests described above and handles Claude Code sign-in. See Anthropic's privacy policy.
  • GitHub hosts the source code, the install script and this website. See the GitHub General Privacy Statement.
  • crates.io serves Rust dependencies when you build mcc. See the Rust Foundation privacy policy.
  • Homebrew, if you install mcc with it, serves the Rust used to build mcc and has its own analytics. See Homebrew's analytics page.

mcc is an independent project and is not affiliated with Anthropic.

This website #

This site is a set of static pages served by GitHub Pages. It sets no cookies, runs no analytics or tracking, and loads no fonts, scripts or images from other hosts. The only script is a small local file that adds copy buttons and highlights the table of contents.

GitHub, as the host, may log technical information about visits, such as IP addresses, for security and operation. That is covered by GitHub's privacy statement, linked above. The project has no access to those logs.

Your control #

  • Turn off usage lookups with mcc list --no-usage or by setting MCC_NO_USAGE=1. mcc then makes no network requests and doesn't read the keychain.
  • Remove a profile with mcc delete <alias>. It signs the profile out and deletes its directory, launcher and alias block.
  • Remove everything by following Uninstall, which ends with rm -rf ~/.mcc.

Because the project never receives your data, there is nothing for it to export or delete on your behalf.

Changes #

If mcc's data handling changes, this page and the changelog will say so, and the effective date above will change. The full history of this page is in the repository.
